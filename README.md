# wav2mp3 — Конвертер WAV в MP3

Простой и быстрый консольный инструмент на Go для пакетной конвертации аудиофайлов из WAV в MP3 с использованием FFmpeg.

## Особенности

- **Параллельная обработка** — до 4 одновременных конвертаций (автоматически подстраивается под количество CPU)
- **Качественное кодирование** — VBR MP3 с качеством `-qscale:a 2` (~190 kbps)
- **Автоматические папки** — создаёт `wav/` и `mp3/` при первом запуске
- **Минимальные зависимости** — только Go и установленный в системе FFmpeg
- **Кроссплатформенность** — работает на Windows, Linux, macOS

## Требования

- **Go 1.21+** (для сборки)
- **FFmpeg** в каталоге `ffmpeg/` рядом с бинарником (с поддержкой `libmp3lame`)

Структура:
```
wavToMp3/
├── wav2mp3.exe
├── ffmpeg/
│   └── ffmpeg.exe     (или ffmpeg на Linux/macOS)
├── wav/
└── mp3/
```

На Windows скачайте FFmpeg с [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) (full build) и распакуйте `ffmpeg.exe` в папку `ffmpeg/`.

## Установка

```bash
# Клонирование
git clone <repo-url>
cd wavToMp3

# Сборка
go build -o wav2mp3.exe
```

Или скачайте готовый `wav2mp3.exe` из релизов.

## Использование

1. Положите `.wav` файлы в папку `wav/` (создаётся автоматически)
2. Запустите:
   ```cmd
   wav2mp3.exe
   ```
3. Готовые `.mp3` файлы появятся в папке `mp3/`

### Конфигурация (config.yaml)

Настройки хранятся в `config.yaml` (создаётся с дефолтами при первом запуске):

```yaml
wav_dir: "wav"
mp3_dir: "mp3"
ffmpeg_dir: "ffmpeg"
workers: 4
quality: 2
bitrate: ""
codec: "libmp3lame"
overwrite: true
verbose: false
```

Можно указать другой конфиг:
```cmd
wav2mp3.exe -config my_config.yaml
```

### Флаги

| Флаг | Описание | По умолчанию |
|------|----------|--------------|
| `-config` | Путь к конфигу YAML | `config.yaml` |
| `-q` | VBR качество (0-9, меньше = лучше) | 2 |
| `-b` | CBR битрейт (например, 128k, 320k) | — (отключено) |
| `-c` | Аудио кодек | `libmp3lame` |
| `-t` | Количество потоков (0 = авто) | 4 (из конфига) |
| `-v` | Подробный вывод | false |
| `-y` | Перезаписывать выходные файлы | true |

### Примеры

```cmd
# VBR качество 3 (по умолчанию 2)
wav2mp3.exe -q 3

# CBR 320 kbps
wav2mp3.exe -b 320k

# CBR 128 kbps, 2 потока
wav2mp3.exe -b 128k -t 2

# Другой кодек с подробным выводом
wav2mp3.exe -c libvorbis -v

# Использовать свой конфиг
wav2mp3.exe -config my_config.yaml
```

## Настройка качества

Настройка качества теперь осуществляется через флаги командной строки:

- **VBR (переменный битрейт)**: `-q 0`...`-q 9` (меньше = лучше)
  - `0` — лучшее качество (~245 kbps)
  - `2` — высокое качество (~190 kbps) **по умолчанию**
  - `4` — хорошее качество (~165 kbps)
  - `9` — минимальное качество (~65 kbps)

- **CBR (постоянный битрейт)**: `-b 128k`, `-b 320k` и т.д.
  - При указании `-b` режим VBR отключается

См. раздел **Флаги** выше для полного списка опций.
